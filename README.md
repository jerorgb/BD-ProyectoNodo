# BD-ProyectoNodo

Este es un proyecto universitario para "Bases de Datos"

Consiste en una api que permite realizar acciones CRUD de una base de datos de
una estidad educativa llamada NODO

Hay 3 tipos de usuarios: Administrador, Profesor y Estudiante, cada uno con distintas funciones,
permisos y accesibilidad a la base de datos

#requerimientos:
- Python 3.+
- SQL
- Workbech (para crear la base de datos)
